## 起動

このフォルダーの index.html をブラウザーで開いてください。Node.js・バックエンド・環境変数は起動に不要です。app.js、app.css、images/、sample/ は一緒に配置します。静的HTTPサーバーでも動作します。

## ログイン

プルダウンで user1〜user5（一般ユーザー）または admin（管理者）を選択します。パスワード欄は無効で、入力・認証検証はありません。管理者画面で追加したユーザーも、このタブ内では選択できます。発行画面のパスワードは表示用の固定値です。

## データ

現在回1回・過去回5回（計6回）、確認済み・未確認・無効の回答を同梱しています。user1〜user4は回答済み、user5は未回答です。user1・user2には全5過去回の回答もあります。実在の利用者データは使用していません。

| 第5回 | 花海 咲季・月村 手毬 |
| 第4回 | 藤田 ことね・有村 麻央 |

| 第2回 | 紫雲 清夏・篠澤 広 |
| 第1回 | 姫崎 莉波・花海 佑芽 |

回答、画像、確認結果、開催設定、追加ユーザー、テーマはJavaScriptのメモリー内だけで管理します。画面移動とログアウト・再ログインでは保持し、再読み込み・タブ終了で破棄します。別タブとは共有しません。LocalStorage、SessionStorage、Cookie、IndexedDB、Cache API、Service Workerは使用しません。Supabaseや本番APIへの通信、外部フォント読込もありません。Blob URLはタブ内の画像表示のみに使用します。CSVは利用者が出力を押した場合のみファイルとして取得します。

## 画面

mainの回答入力・参加履歴・ユーザー登録・回答結果・設定・ログインを使用しています。入力検証、検索、ランキング、CSV、画像確認、ルール編集、画像調整は同じUIです。認証・データ処理だけをメモリーのアダプターへ置き換えました。HTTP配信時はハッシュのルート、ファイル直接起動時はメモリーのルートで遷移します。

## 再ビルド

source/ はmainから抽出したUIとmock用置換ソースです。Node.js 22.12以降で source/ を作業ディレクトリにして npm ci、npm run build を実行すると、配布用app.js/app.cssを再生成します。通常の利用時は再ビルド不要です。mainの変更は自動同期しません。
